Classification Metrics

Accuracy
—

—

—

Specificity
—
TN / (TN + FP)
F1 Score
—
2·(Precision·Recall)/(Precision+Recall)
MCC (Matthews)
—
(TP·TN - FP·FN) / √((TP+FP)(TP+FN)(TN+FP)(TN+FN))
